# Interface design

Native SwiftUI split navigation provides Overview, Backups, Recovery, Blind Investigation, Backup Coverage and Monitoring. Standard controls, semantic typography, headings and keyboard commands support desktop use. Backup/restore actions require complete inventory and explicit review. Monitoring configuration is optional and local.

The icon is an editable layered Icon Composer asset. Synthetic simulator audits cover empty/populated states and Light/Dark appearances. Native window behavior and assistive-technology usability remain separate release gates.
