# Contributing

Use a focused branch and describe behavior and validation in each change. Preserve accessory identities and avoid destructive live Home operations in tests. Use synthetic fixtures, isolated temporary files and the verification commands in README. Run `script/check-public-source.py` before publishing. Never include household exports, keys, credentials, screenshots of real Homes or local configuration in issues or pull requests.

Generate the Xcode project using XcodeGen; edit project.yml rather than generated files. Keep UI audits and production runtime separate. Accessibility exceptions require documented evidence.
